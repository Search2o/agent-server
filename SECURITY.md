# Security policy

Please report security vulnerabilities privately. Do not open a public issue for them.

Email [info@search2o.com](mailto:info@search2o.com) with a description of the problem and,
where possible, the steps to reproduce it. We will acknowledge your report and keep you
informed of the fix.

Please do not include a working exploit in the first message, and please give us a
reasonable time to fix the problem before disclosing it.
