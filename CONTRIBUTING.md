# Contributing to Search2o Agent Server

Search2o Agent Server is proprietary, source-available software.

We welcome:

* Bug reports
* Feature requests
* Documentation feedback
* Security reports

We do not currently accept external code contributions or pull requests.

Please do not submit modified versions of the Search2o Agent Server or patches containing changes to its source code.

For bugs, feature requests, and other feedback, please use the GitHub Issues page for this repository.

Please report security vulnerabilities privately rather than through a public issue.

Use of the Search2o Agent Server is governed by the Search2o Software License Agreement included in this repository.
